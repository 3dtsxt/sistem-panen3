# sistem-panen — Penghitung Hasil Panen & Diskon

**Deskripsi singkat**
Program Python sederhana untuk mencatat hasil panen dari beberapa komoditas/lahan, menghitung total serta rata-ratanya, dan secara opsional menghitung diskon (misalnya untuk potongan harga jual) dari total hasil panen tersebut.

**Cara Menjalankan Program**
- Pastikan Python 3 sudah terpasang di komputer.
- Buka terminal atau command prompt.
- Masuk ke folder proyek dengan perintah `cd sistem-panen`.
- Jalankan program dengan perintah `python3 hitung_panen.py`.
- Masukkan nama komoditas/lahan, lalu jumlah hasil panennya (kg); ulangi untuk data berikutnya.
- Ketik `selesai` pada bagian nama komoditas untuk mengakhiri input.
- Program menampilkan ringkasan: tabel data, total, dan rata-rata hasil panen.
- Jawab `y` jika ingin menghitung diskon dari total hasil panen, atau `n`/Enter untuk melewatinya.
- Jika memilih `y`, masukkan persentase diskon; program akan menampilkan nilai diskon dan total setelah diskon.
